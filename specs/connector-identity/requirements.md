| `CONN-KEYCLOAK-AGENT-CONNECTOR-IDENTITY-R002` | **Realm catalog requires a verified identity.** Before fetching realms, require the SDK entitlement resolver and an authenticated, tenant-bound actor. Caller chain: arbora fleet.call -> `keycloak_agent_realms` tool (keycloak_agent/mcp/mcp_realms.py::register_realms_tools:10) -> keycloak_agent/api/api_client_realms.py::Api.list_realms -> _entitled -> scion_sdk.entitlements.identity_scoped_resources. Test: `tests/test_identity_realm_scoping.py::test_real_authenticated_identity_scopes_the_catalog`. |
| `CONN-KEYCLOAK-AGENT-CONNECTOR-IDENTITY-R003` | **Client catalog auto-load is identity scoped.** Before listing Keycloak clients, require the actor's realm grant.
